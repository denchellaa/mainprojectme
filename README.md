# 🤖 ИИ-агент бизнес-идей

Консольный ИИ-агент, который помогает выбрать формат малого бизнеса и составить план запуска. Главная особенность — **долговременная память**: агент запоминает факты о пользователе (бюджет, город, формат, опыт, цель) и историю диалога между запусками, поэтому не задаёт повторно вопросы, на которые уже получил ответ.

Под капотом — OpenAI `gpt-4o-mini` и простое хранилище `memory.json`.

---

## ✨ Возможности

- **Персистентная память.** Факты и история сохраняются в `memory.json` и подгружаются при следующем запуске.
- **Структурированные факты.** Модель сама выделяет новые факты о пользователе через служебный блок `<MEMORY_UPDATE>`, который автоматически вырезается из ответа.
- **Не переспрашивает.** Известные данные подмешиваются в системный промпт, поэтому агент не задаёт одни и те же вопросы дважды.
- **Понимает короткие ответы.** Ответ вроде `1000000` трактуется как ответ на последний заданный вопрос.
- **Специализация на автобизнесе.** Разбирает форматы: перекуп, автоподбор, комиссионная продажа, привоз авто, trade-in, выкуп проблемных авто — с рисками, маржинальностью и планом на 7 и 30 дней.
- **Консольные команды** для просмотра памяти, истории и сброса.

---

## 🧩 Как работает память

Память хранится в `memory.json` и состоит из двух частей:

```json
{
  "facts": {
    "budget": "1000000",
    "city": "Москва",
    "format": "автоподбор"
  },
  "history": [
    { "role": "user", "content": "...", "ts": "2025-01-01T12:00:00" },
    { "role": "assistant", "content": "...", "ts": "2025-01-01T12:00:05" }
  ]
}
```

- `facts` — структурированные факты о пользователе (ключи в `snake_case`: `budget`, `city`, `business_type`, `format`, `experience`, `goal`).
- `history` — полная история сообщений `user` / `assistant` с временными метками.

**Механизм обновления фактов.** В конце ответа модель добавляет служебный блок:

```
<MEMORY_UPDATE>{"budget": "1000000", "city": "Москва"}</MEMORY_UPDATE>
```

Функция `extract_memory_update()` вырезает этот блок из ответа (пользователь его не видит) и обновляет `facts`. При следующем запросе факты подмешиваются в системный промпт через `build_system_prompt()`.

## 🚀 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить ключ OpenAI

Создай файл `.env` в корне проекта (можно скопировать из `.env.example`):

```env
OPENAI_API_KEY=sk-ваш_ключ
```

### 4. Запустить

```bash
python main.py
```

---

## 🕹️ Команды

| Команда     | Действие                          |
|-------------|-----------------------------------|
| `/help`     | Показать список команд            |
| `/memory`   | Показать сохранённые факты        |
| `/history`  | Показать историю диалога          |
| `/reset`    | Очистить память                   |
| `выход`     | Выйти (также `exit`, `quit`)      |

Любой другой ввод отправляется агенту как сообщение.
